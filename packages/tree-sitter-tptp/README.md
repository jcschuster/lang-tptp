# tree-sitter-tptp

[tree-sitter](https://tree-sitter.github.io/) grammar for [TPTP](https://tptp.org), generated
from the TPTP World `SyntaxBNF` (version recorded in `package.json` under `tptp.bnf`).

`grammar.js` and `queries/highlights.scm` are generated by `mix lang_tptp.gen` in the
[lang-tptp](https://github.com/jcschuster/lang-tptp) repository; do not edit them by hand.
`queries/folds.scm` is hand-written.

```sh
tree-sitter generate
tree-sitter test
tree-sitter build --wasm
```
