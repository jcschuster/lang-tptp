# monaco-tptp

[TPTP](https://tptp.org) language support for [Monaco](https://microsoft.github.io/monaco-editor/):
a Monarch tokenizer generated from the TPTP World `SyntaxBNF` (version recorded in
`package.json` under `tptp.bnf`), plus comment, bracket and auto-closing configuration.

```js
import * as monaco from "monaco-editor"
import {register} from "monaco-tptp"

register(monaco)
monaco.editor.create(element, {language: "tptp", value: "fof(a, axiom, p)."})
```

Monarch is a regex state machine, not a parser: it knows a statement's name and role by
position, and tells functions from constants by a following `(`.

`src/monarch.ts` is generated by `mix lang_tptp.gen` in the
[lang-tptp](https://github.com/jcschuster/lang-tptp) repository.
