# codemirror-lang-tptp

[TPTP](https://tptp.org) language support for [CodeMirror 6](https://codemirror.net/): a Lezer
parser generated from the TPTP World `SyntaxBNF` (version recorded in `package.json` under
`tptp.bnf`), with highlighting, folding and indentation.

```js
import {EditorView, basicSetup} from "codemirror"
import {tptp} from "codemirror-lang-tptp"

new EditorView({extensions: [basicSetup, tptp()], parent: document.body})
```

`src/tptp.grammar` and `src/highlight.ts` are generated by `mix lang_tptp.gen` in the
[lang-tptp](https://github.com/jcschuster/lang-tptp) repository; `src/index.ts` is
hand-written.
